# CurseForge screenshot captions

Screenshots of the Barsmith page (1920x1080), taken with headless Edge from the live page with its Dwarf Shaman example plan.

| File | Title | Description |
|---|---|---|
| 1-planner.png | The planner | Your bars on an in-game-looking screen: pick a class + race, drag spells from the Forever spellbook onto bars 1-8 |
| 2-tooltip.png | Spell tooltips | Hover any button for its Forever tooltip (from Wowhead) plus its slot and key |
| 3-button.png | Editing a button | Click a button to set what goes on it (spell, macro, item or clear) and its key |
| 4-macro.png | Macros | Write macros on the page; Apply creates or updates them in game, matched by name |
| 5-keybinds.png | Keybind mode | Works like the game's quick keybind mode: hover a button, press a key |
| 6-plan-string.png | Plan string | Copy the plan string, paste it into `/barsmith` in game, Check, Apply |
