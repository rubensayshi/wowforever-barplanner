Bar Planner

Plan your action bars, macros and keybinds before you log in. Copy the plan string at the bottom, then in game type /barplan, paste it and press Apply. Needs the BarPlan addon from addon/BarPlan. EllesmereUI shows the result on its bars.

Show:
Keybind mode. Hover a button and press a key, a mouse button (middle, 4, 5) or scroll. Right-click a button to remove its key. Esc ends keybind mode.
Spell Macro Item Cleared by Apply Grey buttons are left as they are. Drag a button onto another to swap them; drag a macro from the list onto a button to place it.
Other keybinds

Movement and targeting. Leave a row empty to keep the game's key for it.

Plan string

Copy this. In game: /barplan, paste with Ctrl+V, press Check to see what will change, then Apply.

    Load a plan

    Paste a string from this page, or from Export my bars in /barplan to start from what you have in game. Loading replaces the current plan.

    How to use it

    1. Copy the addon/BarPlan folder into the game's Interface/AddOns folder (where EllesmereUI is) and enable BarPlan on the character screen.
    2. Plan here. Click a button to choose a spell, macro or item. Turn on Keybind mode and hover a button, then press a key.
    3. In game, out of combat: /barplan, paste, Check, Apply. Spells you haven't learned yet are skipped.
    4. When you learn a planned spell later, BarPlan puts it on its planned button if that button is empty. Turn this off with the checkbox in the window or /barplan auto. /barplan apply runs the last plan again, which also updates spells to their newest rank.
    • Apply only touches buttons and keys that are in the plan. Each planned button or command ends up with exactly the key set here, so other keys on it are removed.
    • A key does one thing: giving Q to a spell takes it off Strafe Left. The planner warns about the game's default keys it replaces.
    • Turn on the bars you use in EllesmereUI's settings (or Edit Mode). Bars 6 to 8 need the client to have them.
    • Macros are matched by name. A macro that already exists with that name is updated. General macros are shared by all characters on the account; tick Character-specific for the 18 per-character ones.
    • Use spell names as they appear in your spellbook. Add a rank in brackets, like Healing Wave(Rank 1), to pin a lower rank (needs Show All Spell Ranks in the spellbook).
    • BarPlan stores the last plan in its SavedVariables. On Forever those only stick between sessions if saving works for you (see ForeverSVFix / EllesmereUI Forever Fix). Applying works either way.
